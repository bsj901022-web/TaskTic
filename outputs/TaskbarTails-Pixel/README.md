# Taskbar Tails — 픽셀 실행판 v0.6.2

작업표시줄 위에서 함께 지내는 작은 픽셀 친구입니다. 캐릭터 25종 (선택 가능), 종류별 특수 모션 2가지, 낙하산 착지, 자리 비움 낮잠과 야간 취침, 친구와 같은 방에서 인사·콕 찌르기·공 던지기·말풍선 공유, 한국어/English UI.

## 실행

1. `app\TaskbarTails.exe`를 더블클릭합니다. 폴더 전체(`app` 안의 DLL·JSON·`assets`·`supabase.json`)가 함께 있어야 합니다.
2. 관리 화면과 기본 모니터 작업표시줄 위에 캐릭터가 나타납니다.
3. Windows용 .NET 8 Desktop Runtime이 필요합니다. 다른 PC에서는 https://dotnet.microsoft.com/download/dotnet/8.0 의 Windows Desktop Runtime을 먼저 설치하세요.

포터블 시제품이며 설치 마법사·자동 업데이트·시작 프로그램 등록은 없습니다. 쓰기 가능한 폴더에 두세요.

모든 캐릭터는 PixelLab으로 생성한 64×64 픽셀 스프라이트입니다. 종류별로 8방향 대기 이미지, 좌·우 16프레임 걷기, 특수 모션 2종 × 16프레임이 `app\assets\<종류>\`에 들어 있습니다.

## 사용법

- 캐릭터 클릭: 쓰다듬기(행복도·경험치 상승, 작은 점프)
- 좌우 드래그: 위치 이동. 위로 끌어올려 놓으면 낙하산을 펴고 바람에 흔들리며 내려와 착지합니다.
- 더블클릭 또는 우클릭 메뉴: 관리 화면 열기
- 관리 화면: 먹이 주기 · 놀아주기 · 재우기/깨우기 · 특수 모션 버튼 2개 · 이름·종류 변경 후 적용
- 설정 카드: 언어(시스템/한국어/English) · 캐릭터가 사는 모니터(작업표시줄 자동 숨김 대응) · 크기 100/150/200% · 자리 비움 낮잠 시간 · 말풍선 스타일 · Windows 시작 시 실행 · 전역 단축키 · 야간 취침 · 스트레칭 알림 · 마주치면 인사 · 마지막 방 자동 참여 · 클릭 효과음. 모두 즉시 적용·저장.
- 캐릭터는 자동으로 작업표시줄 위를 왕복하며(가속·감속), 20~38초마다 특수 모션을 스스로 합니다. 커서를 올리면 멈춥니다.
- 강아지의 "공 물어오기"는 공을 던지고 달려가 물어온 뒤 꼬리를 흔듭니다.
- 고양이·햄스터·여우·몽실 강아지는 잠들면 각각 식빵 자세·동글 휴식·꼬리 이불·엎드린 자세로 쉽니다.
- 말풍선: 관리 화면 아래쪽 "내 캐릭터가 할 말" 칸에 입력하고 Enter(또는 "말풍선 보내기"). 80자까지 자동 줄바꿈되어 캐릭터 위에 표시되고, 방에 연결되어 있으면 친구 화면에도 보입니다.
- 트레이 아이콘 또는 관리 화면의 "종료"로 완전히 종료합니다. 관리 화면 X는 화면만 닫습니다.

## 매일의 작은 반응

- 자리 비움: 키보드·마우스 입력이 설정한 시간(기본 5분) 없으면 낮잠을 자고, 돌아오면 일어나 인사합니다.
- 꺼져 있던 시간: 다시 켤 때 경과 시간만큼 포만감·행복도가 조금 줄어 있고(20/30 아래로는 내려가지 않음) 오랜만이면 "배고팠어"라고 합니다.
- 밤 11시~아침 7시에는 자동으로 잠들고 아침에 일어납니다(설정에서 끌 수 있음). 밤에 직접 깨우면 그날 밤은 다시 재우지 않습니다.
- 50분마다 스트레칭 모션과 함께 잠깐 쉬라고 알려 줍니다(설정에서 끌 수 있음).
- 캐릭터는 40~90초마다 걸음을 멈추고 정면을 보며 상황에 맞는 말을 합니다. 마우스를 올리면 정면을 보고, 빠른 말풍선을 열면 나를 쳐다봅니다.
- 크기 100%는 화면 픽셀 1:1, 150%는 1.5배, 200%는 2배로 픽셀 격자에 맞춰 그려 또렷합니다.
- 말풍선 스타일은 레벨로 해금됩니다(민트 Lv.3, 라벤더 Lv.5, 피치 Lv.8). Lv.10부터 이름이 금색으로 표시됩니다.

## 빠른 말풍선과 반응

- **Ctrl+Alt+T**(기본) 또는 캐릭터 **휠 클릭**: 캐릭터 머리 위에 입력칸이 바로 뜹니다. 입력 후 Enter, Esc로 닫기. 단축키는 설정 카드의 단축키 칸을 누른 뒤 원하는 조합을 눌러 바꿉니다(Ctrl·Alt·Shift + 글자/숫자, 또는 F1~F12). Ctrl+T처럼 브라우저·편집기가 쓰는 조합은 등록되지만 경고가 표시됩니다.
- 입력칸과 관리 화면에 빠른 반응 이모지(❤️ 👋 😂 👍 😢 🎉) 버튼이 있습니다.
- **Ctrl+Alt+P**: 캐릭터 숨기기/보이기(발표·화면 공유 때).

## 친구와 함께 (Supabase)

1. 관리 화면의 "방 만들기 / 참여"를 누릅니다.
2. 방 이름을 입력하고 "방 만들기"를 누르면 초대코드가 표시됩니다. "초대코드 복사"로 친구에게 보내세요.
3. 친구는 초대코드를 입력하고 "코드로 참여"를 누릅니다.
4. 방 창을 닫아도 연결은 유지되고, 관리 화면의 "작은 친구들의 모임" 카드에 방 이름·초대코드·인원이 계속 표시됩니다.
5. 같은 방 친구의 캐릭터가 내 작업표시줄에도 나타나며 위치·걷기·특수 모션·낙하산·말풍선이 실시간으로 공유됩니다.
6. 친구 캐릭터와 가까워지면 서로 인사합니다. 친구 캐릭터를 클릭하면 콕 찌르고(상대 화면에서 폴짝), 우클릭 메뉴나 방 창에서 공을 던지면 상대 화면 가장자리에서 공이 굴러 들어갑니다.
7. 방이 여러 개면 방 창의 "내 방 목록"에서 전환합니다. 전환해도 다른 방의 멤버십은 유지되고, 각 방의 대화와 캐릭터는 분리됩니다. 완전히 나가려면 "이 방 탈퇴". 다음 실행 때 마지막 방에 자동으로 다시 참여합니다(설정에서 끌 수 있음).

서버 준비는 `supabase\설정안내.txt`를 따르세요. 처음 설치는 `setup.sql`, v0.4에서 올리는 경우 `upgrade-v05.sql`을 추가로 실행해야 새 캐릭터 12종이 방에 들어갈 수 있습니다.
익명 로그인 세션은 `app\data\session.json`에 보관되어 같은 PC에서 다시 실행해도 같은 사용자로 이어집니다. 연결이 끊기면 4초→8초→16초 간격으로 자동 재접속합니다.

## 저장과 동작 범위

- 이름·종류·성장 수치·수면·데모 친구 설정: `app\data\pet.json` (15초마다, 변경 시, 종료 시 저장)
- 온라인 세션: `app\data\session.json` (refresh token과 사용자 ID만 저장, 삭제하면 새 사용자로 시작)
- 기본 모니터의 작업영역 아래쪽만 사용합니다. 전체 화면 앱을 감지하면 캐릭터를 숨깁니다.
- 말풍선과 동작은 실시간 이벤트로만 전달되고 서버에 저장하지 않습니다.

## 소스와 빌드

- C# / .NET 8 / WPF / Win32, 외부 NuGet 패키지 없음
- 개발 원본: `C:\app_project\ghrt\work\TaskbarTails`, 보관 사본: `source-pending\`
- 주요 파일: `PetCatalog.cs`(30종 정의, 5종 숨김) · `SpriteLibrary.cs`(스프라이트 로딩·프레임 선택) · `PetVisual.cs`(렌더링·말풍선·낙하산) · `PetWindow.cs`(오버레이·이동·드래그·공 놀이) · `RoomClient.cs`(Supabase 인증·RPC·Realtime) · `RoomWindow.cs`(방 UI) · `App.cs`(수명·트레이·스모크 테스트)

```
dotnet publish work\TaskbarTails\TaskbarTails.csproj -c Release --self-contained false -o outputs\TaskbarTails-Pixel\app
```

실행 검증(관리 화면과 캐릭터를 잠시 생성하고 종료, 일반 저장 파일은 건드리지 않음):

```
app\TaskbarTails.exe --smoke-test verification-run
```

두 명 온라인 연결 검증(실제 Supabase 프로젝트에 익명 사용자 2명으로 방 생성·입장·동작·말풍선·퇴장):

```
cd work\NetworkCheck && dotnet run -c Release
```
