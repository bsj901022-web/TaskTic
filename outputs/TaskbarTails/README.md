# Taskbar Tails — Windows 시제품 v0.1

작업표시줄 위에서 함께 지내는 작은 반려동물입니다.

## 실행

1. ZIP 파일을 받았다면 폴더 전체를 먼저 압축 해제합니다.
2. `실행.cmd` 또는 `app/TaskbarTails.exe`를 더블클릭합니다.
3. 관리 화면과 기본 모니터 작업표시줄 위에 고양이가 나타납니다.

Windows용 .NET 8 Desktop Runtime이 필요합니다. 제작한 PC에는 이미 설치되어 있습니다.
다른 PC에 배포할 때는 https://dotnet.microsoft.com/download/dotnet/8.0 의 Windows Desktop Runtime을 설치해야 합니다.
현재 패키지는 설치 마법사와 자동 업데이트가 없는 포터블 시제품입니다. 실행 파일 옆의 DLL 및 JSON 파일도 함께 보관하세요.

## 사용법

- 캐릭터 클릭: 쓰다듬기, 작은 점프, 행복도 및 경험치 증가
- 좌우 드래그: 작업표시줄 위에서 위치 이동
- 더블클릭 또는 우클릭 메뉴: 관리 화면 열기
- 먹이 주기: 포만감 증가
- 놀아주기: 점프, 행복도 및 경험치 증가
- 재우기 / 깨우기: 수면 상태 전환
- 이름·종류 변경 후 적용: 고양이 또는 토끼 선택
- 데모 친구 2마리: 복숭아와 구름이 표시
- 캐릭터 숨기기: 관리 화면과 트레이를 유지하고 캐릭터만 숨김
- 관리 화면 X: 화면만 닫고 캐릭터는 유지
- 완전 종료: 관리 화면의 종료 버튼 또는 트레이 / 캐릭터 우클릭 메뉴의 종료

캐릭터는 짧게 걷거나 쉬는 행동을 반복합니다. 커서를 올리면 이동을 멈춥니다.
친구 데모는 이 PC에서만 동작합니다. 네트워크 연결, 로그인, 실제 방, 초대코드, Supabase 연동은 아직 없습니다.

## 저장과 동작 범위

이름, 종류, 성장 수치, 수면 상태, 친구 데모 설정은 `app/data/pet.json`에 저장됩니다.
돌봄이나 설정 변경 시, 실행 중 15초마다, 정상 종료 시 저장합니다.
프로그램을 쓰기 가능한 폴더에 두세요. 오프라인 상태이며 외부로 데이터를 전송하지 않습니다.
시제품의 수치는 실행 중에만 시간에 따라 변합니다. 오프라인 성장 계산은 포함하지 않았습니다.
Windows 시작 시 자동 실행이나 시스템 설정 변경은 하지 않습니다.

기본 모니터의 작업영역 아래쪽을 사용합니다. 전체 화면 앱을 감지하면 캐릭터를 숨깁니다.
보조 모니터 선택, 자동 숨김 작업표시줄의 모든 전환 상황, 화면 배율 변경 및 독점 전체 화면 게임은 추가 실기 검증이 필요합니다.

## 소스와 빌드

- C# / .NET 8 / WPF / Win32
- 외부 NuGet 패키지 없음
- 캐릭터는 앱 코드에서 그리는 원본 벡터 그림
- source/PetState.cs: 성장 상태 및 JSON 저장
- source/PetVisual.cs: 캐릭터 렌더링
- source/PetWindow.cs: 투명 오버레이, 행동, 클릭과 드래그
- source/MainWindow.xaml: 관리 화면
- source/Native.cs: 모니터 및 창 위치 API
- source/App.cs: 앱 수명, 트레이, 데모 친구, 실행 검증

.NET 8 이상 SDK가 설치된 Windows에서:

    dotnet publish source/TaskbarTails.csproj -c Release --self-contained false -o build

실행 검증 (관리 화면과 캐릭터를 잠시 생성하고 종료합니다):

    app/TaskbarTails.exe --smoke-test verification-run

검증 모드는 지정한 폴더에 별도 저장 파일을 사용하므로 일반 사용 데이터를 바꾸지 않습니다.
