## 남은 확인·보완 항목

- 보조 모니터 선택, 자동 숨김 작업표시줄, 화면 배율 변경 중 전환, 독점 전체 화면 게임은 실기 확인이 필요합니다.
- 원격 강아지의 공 던지기는 "공을 물고 달리는" 모션만 표시되고 별도 공 창은 로컬에서만 표시됩니다.
- 설치 패키지(MSIX/인스톨러)와 자동 업데이트는 범위에 없으며 포터블 폴더 배포입니다.
- PixelLab 생성 결과의 세부 그림 품질(발 위치, 프레임 간 흔들림)은 종류별로 차이가 있을 수 있습니다. 눈에 띄는 종류가 있으면 `generation-state\jobs.json`의 캐릭터 ID로 해당 모션만 삭제 후 재생성하면 됩니다.

## 재개할 때 참고

- `generation-state\jobs.json`: 22종 캐릭터 ID. 완료 캐릭터를 다시 생성하지 말 것.
- `generation-state\actions.json`: 22종 특수 모션 정의(키·한국어 라벨·프롬프트). 앱의 `PetCatalog.cs`와 키가 일치해야 함.
- `generation-state\status-<종류>.json`: 마지막 조회 스냅샷. 다운로드 URL은 여기서 읽음.
- `generation-state\new-plan.json`, `create.mjs`: 신규 캐릭터 생성 계획과 제출 스크립트 (jobs.json에 없는 종류만 제출).
- `generation-state\motion-batch.mjs`: 모션 생성 재개 스크립트. 완료 상태를 먼저 확인하고 동시 실행 한도 8개를 지킴. 토큰은 stdin으로 전달.
- `generation-state\download-all.mjs`: 상태 스냅샷에서 전체 스프라이트 다운로드. 인자로 종류를 주면 일부만 처리.
- `generation-state\pl.mjs`: PixelLab MCP 도구 단건 호출 CLI (`PIXELLAB_TOKEN_FILE` 환경 변수로 토큰 파일 지정).
- PixelLab 인증값은 인계 파일에 기록하지 않음. Claude Code에는 `pixellab` MCP 서버가 로컬 설정에 등록되어 있음.
- Supabase 클라이언트는 공개 anon 키만 사용하며 service_role 키는 사용하지 않음.
- 새 캐릭터를 더 추가하려면: `new-plan.json`에 설명 추가 → `create.mjs` → `actions.json`에 모션 2종 추가 → `motion-batch.mjs` → `download-all.mjs` → `PetCatalog.cs`에 한 줄 추가 → 빌드.
